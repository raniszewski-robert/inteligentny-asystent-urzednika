# Report format (end every lane assignment with this, nothing else)

```
LANE: <lane id>  PHASE: <phase id>
BRANCH: <branch name>  HEAD: <commit sha>
TICKETS: T<nn> done | T<nn> dropped: <reason> | T<nn> blocked: <what is missing>
SMOKE: green | red (<failing step>)
LLM SPEND: $<x.xx> (cached calls: <n>)
CONTRACT REQUESTS: <changes needed in CONTRACTS.md or another lane's files, or "none">
NOTES FOR TEAM: <max 3 lines: what to look at, what was surprising>
```
