# Taste: Asystent UDIP (Urząd Miasta Bydgoszczy)

Plain official Polish, the register of a BKS letter. The clerk is the reader; the jury sees the same screens.

## Bans

- Exclamation marks in UI copy (T1).
- Uppercase text outside abbreviations (UDIP, BIP, BKS, DOCX) (T2).
- Standalone middle dots or bullets (T3). Kept on purpose: the header "Urząd Miasta Bydgoszczy · Biuro Komunikacji Społecznej" (PLAN.md decision).
- Marketing words about the model ("inteligentny", "magia", "AI" badges); the model is named by provider, and a model badge renders only from a result field.
